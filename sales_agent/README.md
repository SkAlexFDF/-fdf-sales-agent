# FDF · агент контроля менеджеров

Каждое утро (Пн–Сб) агент берёт данные из KeyCRM, считает показатели по каждому менеджеру,
формирует рекомендации и вопросы (Claude) и присылает в Telegram:

1. **Короткую сводку**: главное за вчера, флаги по каждому менеджеру, что сделать сегодня.
2. **Полный дашборд** (HTML-файл): сравнение менеджеров, выручка по дням, зависшие заказы,
   дебиторка, клиенты в риске оттока, ошибки в заказах, рекомендации и вопросы каждому.

## Что контролируется

| Блок | Правило (меняется в `config.py`) |
|---|---|
| Зависшие заказы | Новый > 2 раб. ч, согласование > 8, сборка > 16, доставка > 7 дн |
| Отмены | Доля за 30 дней > 10% |
| Дебиторка | Выполненный заказ без полной оплаты; 8–30 дн жёлтый, 30+ красный |
| Отток | Клиент с ≥2 заказами молчит > 2× своего интервала (мин. 21 дн) |
| Ошибки | Нет телефона, скидка > 15%, нет доставки, заказ без менеджера |
| Отправка/доставка | Зависшие в «Чекає на відправку», «В дорозі», «Прибыл в отделение» — отдельным списком в Telegram |
| Индекс дисциплины | 100 минус штрафы за всё перечисленное (формула внизу дашборда) |

## Недельный и месячный KPI-отчёт

`periodic.py`, расписание в `.github/workflows/kpi_reports.yml`:

- **Понедельник**: прошлая неделя против позапрошлой — выручка, заказы, чек, отмены (общие и сайта),
  новые клиенты, скорость отправки, скидки, «Помилка FDF» и возвраты, заказы без менеджера,
  менеджеры, источники и **списки клиентов «на грани»** (21–40 дней без заказа) для обзвона.
- **1-е число**: прошлый месяц, плюс удержание новых клиентов, повторные покупатели,
  концентрация топ-20% и выручка по линейкам товаров.

Нормы — в конце `config.py` (взяты из анализа CRM за год). Ручной запуск:
Actions → «FDF KPI reports» → Run workflow → week / month.

## Настройка (один раз)

GitHub → Settings → Secrets and variables → Actions:

- `KEYCRM_API_KEY`: ключ KeyCRM (Настройки → API). Агент только читает данные.
- `ANTHROPIC_API_KEY`: ключ Claude API (console.anthropic.com). Без него рекомендации
  строятся по правилам, но вопросы и выводы будут проще.
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`: уже есть для мониторинга обладнання.
- Скрыть менеджера из отчёта: добавить имя в `EXCLUDE_MANAGERS` в `config.py`.
- `SALES_TELEGRAM_CHAT_ID` (необязательно): другой чат для этого отчёта.
- Variable `KEYCRM_ORDER_URL` (необязательно): шаблон ссылки на заказ,
  например `https://ВАШ_АККАУНТ.keycrm.app/app/orders/view/{id}`, чтобы номера в отчёте были кликабельны.

Проверка: Actions → «FDF sales managers report» → Run workflow (галочка «Демо» —
на синтетических данных).

## Локально

```bash
python3 -m sales_agent.main --demo        # демо, без ключей и без отправки
python3 -m sales_agent.main --dry-run     # реальные данные, без отправки
```
